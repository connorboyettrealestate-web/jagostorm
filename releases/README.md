# Releases

Checklists for shipping music. Copy the template into a dated file per release
(e.g. `2026-08-single-nightdrive.md`).

## Release checklist template

```
# <Release name> — <single / EP / drop>

**Target date:** <YYYY-MM-DD>   **Type:** single / EP
**Distributor:** <e.g. BandLab / DistroKid / other>

## Pre-release
- [ ] Final master exported (loudness checked)
- [ ] Cover art done (3000x3000 px)
- [ ] Title, credits, ISRC (if any) confirmed
- [ ] Lyrics / metadata finalized
- [ ] Upload to distributor (allow lead time)

## Launch
- [ ] Release live on stores
- [ ] Social posts scheduled
- [ ] Playlist / share links ready

## Post-release
- [ ] Save what worked to the known-good log
- [ ] Note streams/feedback after 1 week
```
