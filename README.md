# JAGOSTORM

Operating repo for the **Jagostorm** music/artist brand — vocal-chain presets,
production notes, and release plans. This is the durable build layer; the daily
work happens in BandLab and your DAW.

## What's here

| Folder | What lives there |
| --- | --- |
| [`vocal-chains/`](vocal-chains/) | Vocal-chain presets and the Claude Chrome extension playbook for driving BandLab |
| [`productions/`](productions/) | Per-song production notes (one file per track) |
| [`releases/`](releases/) | Release checklists and rollout plans (single, EP, drop) |

## Quick start

1. Building vocals? Open [`vocal-chains/bandlab-presets.md`](vocal-chains/bandlab-presets.md)
   and paste a preset card's prompt into the Claude Chrome extension.
2. New song? Copy a production note template into `productions/`.
3. Shipping? Copy a release checklist into `releases/`.

## What belongs here

- Preset recipes, production notes, lyrics drafts, release plans, checklists.
- Small, reviewable scripts with **no** credentials.

## What does NOT belong here

- Passwords, API keys, tokens, or account logins.
- Copyrighted stems/masters you can't redistribute, or large audio binaries.
- Anything private you wouldn't want in version control.

Keep this repo private while it holds unreleased material.
