# Productions

One file per song/track. Copy the template below into a new file named after the
song (e.g. `nightdrive.md`).

## Template

```
# <Song title>

**Status:** idea / tracking / mixing / mastering / done
**BPM:** <tempo>   **Key:** <key>   **Started:** <YYYY-MM-DD>

## Concept
<one-line vibe / reference track>

## Vocal chain used
<which preset from ../vocal-chains/bandlab-presets.md + any tweaks>

## Arrangement notes
<sections, hooks, ad-libs, doubles>

## To-do
- [ ] tracking
- [ ] comp/tune vocals
- [ ] mix
- [ ] master
- [ ] export / release

## Links
<BandLab project link, stems location — no logins>
```
